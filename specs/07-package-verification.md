# Проверка пакета спецификации 0.1.0

Дата: 08.09.2026. Проверка относится к документам, начальным контрактам и дизайн-макету.

## Выполнено

| Объект | Результат |
|---|---|
| 2 JSON Schema | Схемы корректны для Draft 2020-12 |
| Конфигурации 1 / 10 / 1000 | Валидны по схемам и реализованным смысловым проверкам |
| 3 примера событий | Валидны; уникальные IDs, последовательный sequence |
| Локальные ссылки Markdown | Проверены существующие целевые файлы |
| JavaScript макета | Синтаксическая проверка пройдена |
| 1 агент, C=1, без памяти | Прямой режим отображается; нет дополнительного координатора |
| Некорректные N=1, C=2 | Применение отключено; показана причина |
| N=1000, C=10 | Счётчики соответствуют настройкам; поиск выбирает agent-999 |
| N=5000, C=10 | Граф отрисован; поиск выбирает agent-5000 |
| Координатор / память | Наблюдались независимые сочетания on/off |
| Добавление 12 к 10 | Итог 22; выбран новый agent-011, счётчики групп 17+3+2 |
| MCP | До демо-проверки подключение недоступно; STDIO/HTTP формы различаются |
| Демо-задача | Отображается с выбранным получателем в списке |
| Разделы | Граф, Агенты, MCP, Задачи, Обзор, Знания, Запуски открываются |
| Pause / Stop | Число работающих в демо становится 0, событие записывается |
| Клавиатура графа | ArrowRight меняет выбранного агента с agent-011 на agent-012 |
| Ошибки браузерного JavaScript | Во время описанной проверки не наблюдались |
| Визуальные референсы | Три PNG просмотрены и скопированы в design/references |

Макет проверялся в браузере приложения, включая viewport 1280×800. Найденные проблемы реакции поиска и обрезанных подписей исправлены. Полная WCAG-проверка, измерение fps и проверка всех breakpoints не проводились.

## Не выполнялось на этапе спецификации

Реальные turn Codex, OAuth/ключи пользователя, запуск MCP/БД, измерения CPU/RAM провайдера, 10/1000 CLI одновременно, длительный soak, восстановление production-БД и выпуск installer.

Отрисовка 5000 демонстрационных узлов подтверждает работоспособность этого макета в наблюдаемой среде. Она не является доказательством runtime capacity или выполнения NFR production-приложения.

Исходные главы спецификации остаются Proposed. Полный план последующих проверок находится в 05-delivery-and-acceptance.md.
